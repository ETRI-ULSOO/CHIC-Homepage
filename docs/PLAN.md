## 1. 먼저 확정해야 할 결정 (뒤집히면 재작업이 큼)

### P-01 · 다이어그램 SVG 재제작 범위 — **가장 큰 변수**

[[DESIGN]] 개정으로 다이어그램은 시스템 팔레트 SVG가 원칙이 되었다. 현행 사이트의 **구조 다이어그램은 11점**이다 (Results의 결과물 썸네일 39건은 스크린샷·사진이므로 재제작 대상이 아니라 카드 내부 기능 이미지다).

| 페이지 | 다이어그램 | 비고 |
|---|---|---|
| Home | 2 | 본문 1 + 연구개발의 필요성 1 (**1점 재제작 완료**) |
| Project / About | 2 | 과제 개요 1 + 기대효과 1 |
| Concept and Approach | 4 | 이 페이지는 사실상 다이어그램이 본문 전체 |
| Ambition and Objectives | 1 | **이 1점이 페이지의 전부** |
| Consortium | 1 | 연구개발 추진체계도 |
| Results | 1 | 연차별 활용 계획 |

선택지:

| 안 | 내용 | 대가 |
|---|---|---|
| **A. 전량 재제작 (11점)** | 전부 시스템 팔레트 SVG로 다시 그림 | 작업량 최대. 대신 판독성·일관성·확대 품질 모두 확보되고 원본 파일 부재(M-02)가 무력화됨 |
| B. 단계적 재제작 | 랜딩(Home·Project·Consortium) 5점 우선, Concept·Results 6점은 원본 이미지로 임시 | 한 페이지 안에서 섞이지만 않으면 허용 가능. 다만 Concept 페이지가 통째로 임시 상태로 남음 |
| C. 재제작 없음 | 전부 원본 추출 이미지 사용 | [[DESIGN]] 개정을 되돌려야 함. 흰 배경 액자 방식으로 회귀 |

> **권장: A.** 근거 셋 — ① 원본 파일 보유가 불확실(M-02)한데 재제작은 그 의존을 없앤다. ② SVG는 확대해도 깨지지 않아 판독성 문제(이 사이트의 최대 약점)가 근본 해소된다. ③ 11점은 텍스트가 이미 인벤토리에 확보되어 있어 재제작 단가가 낮다.
> **A 채택 시 M-02(원본 확보)는 자동 해소되고, 필요한 것은 원본 파일이 아니라 '현행 다이어그램의 내용이 맞는지 검수'로 바뀐다.**

### P-02 · 영문 콘텐츠 부재 처리 (M-01)

Consortium·News 영문판이 존재하지 않는다. D-02(한·영 완전 대응)와 충돌한다.

| 안 | 내용 |
|---|---|
| A. 신규 번역 | News 게시물 5건 본문 + 첨부 라벨 번역. 기관명은 공식 영문명으로 이미 확보 |
| B. 영문판 축소 | 영문은 Home·Project·Results만 제공하고 News·Contact은 국문으로 폴백 |
| C. D-02 철회 | 영문 병기를 부분 대응으로 하향 |

> **권장: A.** News 5건은 분량이 적고(각 2~4문장), 국제 협력 노출이 D-02의 원래 목적이다. 초안은 작성 가능하나 **연구 용어의 최종 표현은 검수가 필요하다.**

### P-03 · 중복·빈약 페이지 정리 (M-03, M-04)

- `/project`와 `/project/about`는 **콘텐츠가 완전히 동일**하다 → 하나로 통합하고 다른 하나는 리다이렉트
- `Ambition and Objectives`는 **다이어그램 1점 외 텍스트가 없다** → 독립 페이지로 두면 빈 페이지처럼 읽힌다

> **권장:** 하이브리드 IA(D-11)에서 Project 관련 3페이지를 랜딩의 `#project` 섹션 하나로 합치고, Ambition 다이어그램은 그 안의 도해로 배치한다. 구 URL은 리다이렉트로 살린다.

### P-04 · Results 결과물 이미지 39건

각 항목에 썸네일이 붙어 있으나 원본 화질·저작권 상태가 미확인이다.

> **권장:** 1차 구현은 **텍스트 전용 레이아웃**으로 완성하고(이미지 부재 시 자연 축약되도록 `ResultCard` 설계 — [[DESIGN]] 명시), 이미지는 확보되는 대로 추가한다. 이미지 대기 때문에 Results 페이지 전체가 막히지 않게 한다.

### P-05 · News 첨부 (M-06)

첨부 14건이 전부 Google Drive 링크다. Google Sites를 폐기해도 Drive 링크는 살아 있으나, **소유 계정·공유 설정에 종속**된다.

> **권장:** 링크 유지 + 외부 링크 표기(↗). 단, 발표자료 9종은 저장소 이관을 검토할 가치가 있다 — 과제 성과물의 영속성 문제다. **이관 여부는 저작권 확인이 선행되어야 하므로 이번 범위에서 제외한다.**

## 2. 데이터 모델 (P-01~P-05 확정 후 고정)

```
src/content/
  news/{ko,en}/<slug>.md          # 파일명이 언어 간 연결 키
src/data/
  home.yaml                        # id: ko | en
  project.yaml                     # id: ko | en — 연구목표·연구내용·결과물
  consortium.yaml                  # 기관 7 (ko/en 병기 + order)
  results.yaml                     # 결과물 39 (ko/en 병기 + order)
```

### results.yaml 스키마 (신규 확정 — 인수인계 문서의 '논문·특허' 전제 폐기)

```yaml
- id: y2-02-04
  year: 2            # 1 | 2 차년도
  category: asset    # acquisition | asset | analysis | platform | service
  order: 24          # getCollection이 id 알파벳순이므로 명시 정렬 필수
  ko: { title: 문화유산 애셋 표준 생성, desc: ... }
  en: { title: ..., desc: ... }
  image: /images/results/y2-02-04.webp   # 선택 — 없으면 텍스트 전용 렌더
```

`category` 5종은 현행 2차년도 대분류를 그대로 승계한다. 1차년도 15건은 분류가 없으므로 `category`를 역매핑해 부여한다 — **이 역매핑은 내용 판단이 필요하므로 검수 대상이다.**

## 3. 라우트 맵

| 경로 | 내용 |
|---|---|
| `/` | → `/ko/` 리다이렉트 |
| `/{locale}/` | 랜딩 — Hero · KPI · `#project` · `#concept` · `#consortium` · `#contact` |
| `/{locale}/results/` | 결과물 39건, 연차·대분류 필터 |
| `/{locale}/news/` | 게시물 목록 |
| `/{locale}/news/{slug}/` | 게시물 본문 |
| 구 URL 6종 | `/project/about` 등 → 대응 앵커로 리다이렉트 |

전 페이지가 `src/pages/[locale]/…` 패턴을 따른다 — 언어별 페이지 파일 복제 금지 (G4 합의).

## 4. 구현 순서 (Walking Skeleton 우선)

| # | 단계 | 검증 기준 |
|---|---|---|
| 1 | 랜딩 전 섹션 완성 (`#project`·`#concept`·`#contact` 추가) | `npm run build` 통과, 한/영 양쪽 전 섹션 렌더 |
| 2 | 다이어그램 SVG 재제작 (P-01 범위대로) | 각 SVG 텍스트 4.5:1 / 도형 3:1 실측 통과 |
| 3 | `results.yaml` 39건 입력 + Results 페이지·필터 | 필터 전환 시 항목 수 일치, 이미지 없는 항목도 정상 렌더 |
| 4 | News 목록·본문 + 첨부 링크 | 5건 전부 렌더, 외부 링크 `rel="noopener"` 확인 |
| 5 | 구 URL 리다이렉트 | 6종 전부 200 또는 의도한 앵커 도달 |
| 6 | 폰트 서브셋 자체호스팅 (M-09) | Google Fonts 의존 제거, LCP 개선 확인 |
| 7 | Cloudflare Pages 연결 | 첫 배포 성공, 한/영 라우팅 정상 |

**1~2단계를 먼저 관통한 뒤** 3~4단계를 채운다. 콘텐츠 입력량이 많은 Results를 앞에 두면 껍데기 검증이 늦어진다.
